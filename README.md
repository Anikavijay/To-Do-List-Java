# To-Do-List-Java
A beginner-friendly To-Do List application built using Java, arrays, loops, and conditional statements.

## About the Project
This is a beginner-friendly console-based To-Do List application developed using Java. It helps users manage daily tasks through a simple menu-driven interface.

## Features
- Add multiple tasks
- View all tasks with numbering
- Delete a task by its number
- Mark tasks as completed
- Prevent duplicate completion marking
- Validate task numbers and handle an empty task list
- Limit the task list to a maximum of 10 tasks

## Technologies Used
- Java
- Arrays
- Loops
- Conditional Statements
- Scanner for User Input

## How to Run
1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open a terminal in the folder containing `todo.java`.
4. Compile the program:
   `javac todo.java`
5. Run the program:
   `java todo`

## Current Limitations
- The application supports up to 10 tasks.
- Tasks are not saved permanently after the program closes.
